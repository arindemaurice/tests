LOVE IS LIKE CODING (plain HTML version)
Open index.html in Chrome, Edge or Firefox. No server or install needed.
Pages: index.html (poem), register.html, login.html, dashboard.html.
Settings (WhatsApp number, backgrounds, your photos/video): js/config.js
NOTE: accounts are stored in the visitor's own browser (localStorage), so they work on
that device only and the heart status is not shared with you. For accounts that live on a
server, use the Flask version (love-is-like-coding.zip).
